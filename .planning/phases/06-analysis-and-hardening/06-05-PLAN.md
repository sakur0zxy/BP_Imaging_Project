<objective>
改进点目标分析中的旋转角度估计，避免局部框过大或附近亮点进入 patch 时，把其它目标/伪影误当成当前点目标旁瓣主轴。

当前 `point_target_analysis.m` 的角度估计使用边缘列峰值拟合：在上采样 patch 的左右边缘列寻找每列最大值，再通过直线拟合得到倾斜角。这种方法在单点目标、干净局部框下很快，但当 cutout 框过大、附近点目标或强伪影进入边缘区域时，峰值轨迹会被污染，导致旋转角估计错误。

本计划新增一个基于旁瓣环带的角度估计方法：以点目标峰值为中心，在 dB 域排除中心主瓣和低能噪声，仅保留旁瓣环带；将环带像素角度折叠到 90 度周期内，统计角向能量分布，用能量峰值估计旁瓣主轴方向，并以相反角度进行图像旋转校正。
</objective>

<locked_decisions>
- 新方法命名为 `sidelobe_ring`，作为默认旋转角估计方法。
- 旧方法保留为 `legacy_edge_fit`，用于回退和对比，不删除。
- 旋转校正总开关仍然使用 `analysis.pointTarget.enableTiltCorrection`。
- 角度估计方法由 `analysis.pointTarget.tiltMethod` 控制。
- 新方法只作用于点目标分析的局部 patch，不改变 BP 成像、恢复、缺失控制或 recovery evaluation 主契约。
- 如果旁瓣环带有效像素不足或角向峰值不明显，必须跳过旋转或返回 0 度，不能强行旋转。
- 新增诊断信息写入 `pointResult.rotation`，便于后续调试。
</locked_decisions>

<target_algorithm>
建议算法流程：

```text
输入：上采样后的局部点目标 patch
1. 找到 patch 内峰值位置，作为当前点目标中心
2. 计算幅度 dB 图，并相对峰值归一化为 0 dB
3. 构建半径图和极角图
4. 排除中心主瓣区域，例如高于 mainlobeExcludeDb 的像素
5. 排除低能噪声区域，例如低于 sidelobeFloorDb 的像素
6. 限制半径范围，避免过远附近点目标进入角度估计
7. 将角度折叠到 90 度周期内
8. 按 angleBinDeg 分箱统计角向能量
9. 取角向能量峰值作为 estimatedTiltDeg
10. 若有效像素数或峰值对比度不足，标记 skipped 并返回 0 度
```
</target_algorithm>

<config_contract>
新增或补齐以下配置字段，默认值要保守：

```matlab
config.analysis.pointTarget.tiltMethod = 'sidelobe_ring';
config.analysis.pointTarget.tiltMainlobeExcludeDb = -6;
config.analysis.pointTarget.tiltSidelobeFloorDb = -35;
config.analysis.pointTarget.tiltMinRadiusPixels = [];
config.analysis.pointTarget.tiltMaxRadiusPixels = [];
config.analysis.pointTarget.tiltAngleBinDeg = 1;
config.analysis.pointTarget.tiltMinValidPixels = 30;
config.analysis.pointTarget.tiltMinPeakContrast = 1.5;
```

说明：
- `tiltMainlobeExcludeDb` 用于剔除中心主瓣强能量。
- `tiltSidelobeFloorDb` 用于剔除低能噪声。
- 半径参数为空时由 patch 尺寸和上采样倍数自动推断。
- `tiltMinPeakContrast` 用于判断角向能量峰值是否足够明确。
</config_contract>
