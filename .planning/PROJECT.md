# BP Imaging Project

## What This Is

这是一个基于 MATLAB 的 BP SAR 成像重建项目。它参考旧仓库 `gotha_bp_project` 的算法与数据链路，但按新的清晰架构重建为“配置分层、数据契约统一、实测与仿真流程分离、输出与运行时支撑独立”的工程化版本。

第一目标不是一次性搬完全部旧代码，而是按阶段稳定重建，先把公共基础层、实测主链路和可维护接口重置到清晰状态，再逐步接入仿真、恢复、分析和测试。

## Core Value

把旧 BP 成像项目重建成一个结构清楚、变量易懂、注释简洁、可以长期演进的 MATLAB 工程。
